# シミクレール LINEボット

ルールベースの自動応答ボットです。AI API（Claude/ChatGPT等）は使用していないため、
メッセージ量に応じた従量課金は発生しません。ランニングコストはサーバーのホスティング費用のみです。

## できること・できないこと

- FAQ（送料・発送日数・支払い方法・返品条件・使い方・定期便の有無・診察パスワード）に固定回答で即答
- 「ニキビに効きますか」等の効能質問は、個人差がある旨の定型文で自動的にかわす
- 健康被害の申告（かぶれ・赤み等）と注文トラブル（未着・破損等）には、**受付メッセージ（「担当スタッフより確認のうえ、順次ご連絡いたします」）だけを自動で返し**、内容への回答はしない
  → この2種類と、どのルールにも当たらなかったメッセージ（汎用の返信）は、
    LINE公式アカウントマネージャー（管理画面）の受信箱をスタッフが定期的に確認し、そこから直接返信してください。
    ボットが自動で医師やカウンセラーに取り次ぐことはしません（設計方針通り）。

## 必要な準備（ご自身で行ってください）

1. LINE Developersコンソールで、開設済みのLINE公式アカウントに紐づく
   「チャネルアクセストークン」と「チャネルシークレット」を発行する
   （これらは認証情報のため、私が代わりに取得・入力することはできません）
2. 上記2つを、デプロイ先の環境変数として設定する
   - `LINE_CHANNEL_ACCESS_TOKEN`
   - `LINE_CHANNEL_SECRET`
3. LINE Developersの「Messaging API設定」で、Webhook URLに
   デプロイ先のURL＋`/webhook`（例：`https://your-app.onrender.com/webhook`）を設定し、
   「Webhookの利用」をONにする
4. 応答モードを「Bot」に設定する（LINE公式アカウントマネージャーの応答設定）

## 回答内容のカスタマイズ

`index.js` 内の `rules` 配列に、キーワードと固定回答をまとめています。
回答の数字（送料1,000円・15,000円以上無料、入金後5営業日以内に発送、支払い方法、
返品は不良品・誤配送のみ到着後7日以内）は、2026年11月時点のShopifyの設定・ポリシーに合わせています。
ストアの設定を変えたら、ここも必ず直してください。

## 試験（変更のたびに実行）

```
node test/run-tests.js       # 質問187件の分類が正しいか
node test/content-check.js   # 返信の中身（送料・支払い方法など）が今の設定と合っているか
```

`test/cases.json` に質問と期待する分類を追加すれば、試験を増やせます。

## 精度の目安と限界（2026年11月10日の試験）

- 精度は「修正に使っていない新しい質問」で測る。チューニング済みの `cases.json` の100%は実力ではない
- 11月10日：新しい質問42問（`test/holdout-2026-11-10.json`）で、改善前81% → 改善後83%（35/42）
  - 外れ7件のうち5件は汎用の返信（スタッフ対応）に回ったもの。誤った事実（送料・支払い方法など）を返したものは0件
  - 1件だけ関係のない定型文を返した（「明日までに欲しいのですが間に合いますか」に効能の定型文）→ その後修正済み
  - 外れた例は `cases.json` に追加して修正済み。このため、このセットはもう「新しい質問」としては使えない。次回は別の新しい質問を作って測る
- 解消済みの誤検知：「ポイントカード」→支払い回答、「痛快」→健康被害扱い、「変更点」→注文トラブル扱い（`index.js` の `NEUTRAL_WORDS`）
- キーワード一致のため、言い回しが想定外だと汎用の返信になる。汎用の返信の受信箱確認は必須
- 誤検知・取りこぼしを見つけたら `test/cases.json` に追加してからキーワードを直す

## さらに精度を上げたい場合（案）：AIに「分類だけ」させる

AIに自由に回答させるのではなく、「この質問は送料・支払い・健康被害…のどれか」だけをAI（Claude API）に判定させ、
返信は今と同じ固定文から選ぶ方式。誤った情報や効能の断言をAIが書く余地はない。

- 費用の目安：最も安い Claude Haiku 5.5（入力100万トークンあたり0.10ドル、出力0.50ドル）で、1通あたり約0.0001ドル。
  月1,000通でも約15円程度
- 安全策：健康被害の言葉（かぶれ・赤み等）はAIより先にキーワードで判定して必ずスタッフ対応に回す。
  AIの応答が遅い・失敗した・自信がない場合は汎用の返信（スタッフ対応）に回す
- 必要なもの：AnthropicのAPIキー（サーバーの環境変数に設定。チャットには貼らない）
- 導入前に、今と同じ方法（新しい質問セット）で精度を比べてから判断する
